# Exempel

Körbara Scheme-uttryck som fungerar i tolken. Kör ett exempel genom att klistra in
det i REPL:en:

```bash
dotnet run --project SICP
```

Förväntat resultat står som kommentar efter `; -->`.

| Fil | Visar |
|-----|-------|
| [factorial.scm](factorial.scm) | Rekursion, `define` med procedur, `if`, aritmetik |

Nya exempel: lägg till en `.scm`-fil och en rad i tabellen. Håll dem små och
verifierade mot en faktisk körning.
